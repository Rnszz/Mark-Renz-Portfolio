# Mark Renz — Developer Portfolio

This folder contains the current portfolio source split into separate files.

## Files
- `index.html` — page structure and portfolio content
- `assets/styles.css` — layout, colors, responsive styling, and chatbot appearance
- `assets/script.js` — current page interactions and the rule-based demo chatbot

## Preview locally
1. Extract the ZIP if you downloaded it.
2. Keep the `index.html` and `assets` folder together.
3. Open `index.html` in a browser.

## Important chatbot note
The current chatbot is a rule-based demo. It does not call an AI model or backend yet.
When adding real AI, the browser should call your own backend endpoint; keep secret API keys on the server, never in `assets/script.js`.
