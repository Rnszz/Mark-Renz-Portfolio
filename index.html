How I work

Learn. Build. Improve.

My approach is to build in small, testable steps and understand how the pieces fit together.

01 / UNDERSTAND

Start with the user problem

Clarify what the application should help people do before choosing a technical solution.

02 / STRUCTURE

Keep responsibilities clear

Separate interface, application logic, and data concerns so features remain easier to test and maintain.

03 / ITERATE

Test on real workflows

Check interactions, handle errors, and improve based on actual behavior rather than appearance alone.

04 / COLLABORATE

Use version control

Track changes with Git, communicate clearly, and make project progress visible to teammates.
